### 🤖 [PrepPilot AI](https://github.com/dixant-sharma/PrepPilot)

AI-powered interview preparation and career coaching platform built with the MERN stack and LLM APIs.

**Highlights**
- 13 REST endpoints with 10 JWT-protected endpoints
- Technical and HR interview tracks with adaptive follow-up questions
- LLM-based answer evaluation
- Speech analytics using the Web Speech API
- STAR-based behavioral evaluation
- AI Career Memory for tracking weak topics and readiness
